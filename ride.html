How to time a ride
  1. When you board, type the route, and the bus's fleet number or registration if you can see it, then tap Start ride. Allow location: it is how each stop is found.
  2. The box at the top shows the stop before, the stop the bus is at, and the stop after. If the stop is wrong, choose the right one there before you tap.
  3. At each stop, tap Doors open as the doors open and Doors closed as they close. If you miss one, tap the other: the stop is still logged.
  4. If the bus goes past a stop without stopping, tap Stop skipped as it passes. If it stops where there is no stop (lights, a driver change), tap Unscheduled stop, then Moving again when it moves off.
  5. Check each row in the list below and add a note for anything unusual. Tap End ride when you get off, and export at the end of the session.
