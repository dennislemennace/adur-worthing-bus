How to time a ride
  1. When you board, type the route, and the bus's fleet number or registration if you can see it, then tap Start ride. Allow location: it is how each stop is found.
  2. At each stop, tap Doors open as the doors open and Doors closed as they close. If you miss one, tap the other: the stop is still logged.
  3. Check the stop shown for each row in the list below, and change it if the guess is wrong. A note is useful for anything unusual: a ramp, a driver change, waiting for time.
  4. Tap End ride when you get off, and export at the end of the session.
